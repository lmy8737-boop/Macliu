# 关键变量清单模板

用于任何 `Y`/`R` 级任务开始时，把主论点拆解成可核验的关键变量。方法论详见《结论纪律与反方检查》。

先写一句话论点：

> <一句话论点>

再列关键变量（常规研究 5-12 个，正式深度报告 10-20 个，不为凑数扩表）：

| # | 变量 | 当前值/主张 | 为什么重要 | 来源 | 来源等级(P0-P3) | 主张类型 | 验证状态 | 获取状态 | as_of | 敏感度(A/B/C) | 证伪条件 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 1 | | | | | | | | | | | |
| 2 | | | | | | | | | | | |

字段取值说明：

- **来源等级**：P0（一手披露/官方资料/结构化数据）/ P1（可信事实报道/行业研究）/ P2（卖方研报/专家会）/ P3（KOL/小作文）
- **主张类型**：`fact` / `third_party_view` / `guidance` / `model` / `scenario`
- **验证状态**：`original_checked` / `independent_cross_checked` / `single_source_unverified` / `conflicted` / `unverified`
- **获取状态**：`ok` / `partial` / `empty` / `stale` / `error`
- **敏感度**：A（单项错误足以推翻核心论点）/ B（改变情景概率但不单独推翻主线）/ C（背景信息）

**A 级变量必须逐一回到一手来源核验**，并在下方登记核验记录：

| 变量 | 一手来源（页码/表格/段落/公告章节） | 核验结果 | 核验日期 |
|---|---|---|---|
