# 投研知识库首页

欢迎。这个 Obsidian 知识库不是一个空文件夹——它已经内置了一整套投研纪律（六步流程、证据分级、G/Y/R 风险门、11 角色委员会）和知识库写入规范，你的 agent 打开这个仓库工作时会自动遵守。

**第一次用？** 先看 [[新手上路]]，两分钟了解怎么开始你的第一份研究。

## 这个知识库怎么组织

| 目录 | 放什么 |
|---|---|
| `00_Inbox` | 临时线索、还没来得及整理的想法、别人发的文章 |
| `01_每日投研` | 按日期记录的日常研究日志 |
| `02_资料收集` | 原始材料，以及 `结构化数据/` 子目录——可复用的数字（估值、财务指标、跟踪表）单独存在这里，不要只写在正文里 |
| `03_公司研究` | 单家公司的深度研究笔记，一家公司一个文件，持续更新，不要每次研究都开新文件 |
| `04_行业研究` | 行业/产业链研究 |
| `05_投资主题` | 跨公司、跨行业的主题研究（比如"AI算力供应链""国产替代"这类） |
| `07_输出与报告` | 需要导出、分享给别人的成品报告 |
| `09_附件` | 图片、PDF 等附件 |

## 方法论在哪

不在这个 `00_首页` 里——完整的研究方法论（六步流程、证据分级、角色委员会、写入规范）在仓库根目录的 [`SKILL.md`](../SKILL.md)，以及它引用的 [`references/`](../references/) 目录。你的 agent 应该已经读过这些；如果它表现得不太对劲（比如把卖方观点当事实、结论没有反方、每次研究都开新文件），提醒它重新读一遍 `SKILL.md`。

## 常用模板

写新研究时不用从空白开始，从 [`templates/`](../templates/) 挑一个：

- [`公司研究模板.md`](../templates/公司研究模板.md) — 个股深度研究
- [`行业主题模板.md`](../templates/行业主题模板.md) — 行业/产业链/主题研究
- [`快速判断模板.md`](../templates/快速判断模板.md) — 不需要走完整流程的快速问答
