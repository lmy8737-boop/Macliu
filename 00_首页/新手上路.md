# 新手上路

装好这个知识库之后，直接跟你的 agent（在 Obsidian 里配合 Claude Code / Codex / Cursor 等任何能读写这个文件夹的 agent 使用）说话就可以开始研究了，不需要先学一遍方法论文档——agent 已经读过 `SKILL.md`，规则由它来遵守。

## 试着说这些看看

**研究一家公司：**
> 帮我研究一下 <公司名>，这家公司值不值得关注？

**研究一个行业/主题：**
> 帮我看看 <某个行业/产业链/主题> 现在处于什么阶段，谁最受益？

**核实一个传闻或说法：**
> 我听说 <某个说法>，这个靠谱吗？

**快速判断，不用写成正式笔记：**
> 快速告诉我 <某个问题的判断>，给我结论和三条证据就行。

## 你会看到什么不一样

- 结论不是"我觉得"，而是标了来源等级的（一手公告 P0、卖方研报 P2 观点、小作文 P3 线索），Agent 会告诉你哪些是事实、哪些只是别人的猜测。
- 正式的分析类结论结尾会有"镜子测试"收口：买/不买的理由、护城河判断、估值位置、下行风险、一句话结论——五个都有才算真正的结论，证据不够 agent 会老实说"证据不足"，不会为了给你一个答案硬编。
- 涉及买卖、仓位这类真实交易决策时，agent 只会给建议和一份"人工必读清单"，不会替你做最终决定——这是设计上的红线，不是它偷懒。
- 研究会自动写进知识库对应的文件夹（`03_公司研究/`、`04_行业研究/` 等），同一家公司下次再问会在旧笔记基础上更新，而不是每次开一个新文件。

## 想要更深的研究方法

看仓库根目录的 [`SKILL.md`](../SKILL.md)，那是完整方法论说明；`references/` 目录下有更详细的证据分级、角色调度、写入规范文档。日常使用不需要自己读这些——直接对 agent 提要求就行，方法论是给 agent 遵守的，不是给你背的。

看 [`examples/示例_行业快速判断.md`](../examples/示例_行业快速判断.md)，一个完整虚构案例，演示从提问到给出结论的全过程。
