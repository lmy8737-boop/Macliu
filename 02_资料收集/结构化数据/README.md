# 结构化数据

这个目录存放可复用的数字：估值、财务指标、市场规模、打分/跟踪表——任何"下次研究可能还要用到、不想再翻一遍正文去找"的数据。

## 怎么新建一张表

字段规范见 [`../../templates/结构化数据字段规范.md`](../../templates/结构化数据字段规范.md)，最小字段集是：`entity`（对象）、`metric`（指标）、`value`、`unit`、`period`/`as_of`（时点）、`source`、`source_level`（P0-P3）、`claim_type`、`verification_status`。

## 两条规则

1. **优先向已有表追加新的一行**，不要每次新建一个内容重复的滚动副本——同一个指标、同一个实体的历史序列应该沉淀在同一张表里。
2. **不要覆盖历史数据**，需要修正时保留旧版本行并写清楚订正原因（呼应《知识库写入规范》的"旧数据用删除线保留"原则）。

目前这里还没有任何表——你的第一次研究产生可复用数字时，agent 会在这里新建。
