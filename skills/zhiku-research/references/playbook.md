## 一、三种产出形态的详细打法

### 形态 A：个股深度（最常用）

骨架：封面索引 → 执行摘要（结论先行）→ 概况 → 业务图解 → 财务 → 毛利率产业链对比 → 4-6 个专题（覆盖关键问题）→ 场景 → 估值 → 风险 → 结论+追踪 → 数据核查。

要点：
- **执行摘要第一句必须是判断**，不是背景。"一句话结论：基本面是 X，但估值已透支，等回调"。
- **每个关键问题独立成专题或小节**，标题直接用问题（"专题三（核心问题）：A股有没有公司能替代它？"）。
- **维度表**：执行摘要后放一张"维度 | 核心结论"表，6-8 行，让人 30 秒抓全貌。

### 形态 B：横向对比专栏（如易中天）

骨架：三句话定性 → 全维度对比总表 → 财务对比 → **商业模式分野（核心）** → 最关键差异 → 逐公司小节 → 估值对比 → 投资排序与选择逻辑 → 风险 → 数据核查。

要点：
- **核心是找"本质分野"**，不是平铺三家。易中天的灵魂洞察：旭创=规模龙头、新易盛=弹性、天孚=卖铲人；**最关键差异是面对 CPO 命运相反**（旭创/新易盛被威胁，天孚反受益）。
- **"如果你认为…→ 首选…"决策表**：把选择权还给用户，列出不同判断对应不同标的。
- 每家保留独立深度个股（专栏做横向，个股做纵向），交叉双链。

### 形态 C：产业链源头/地基（如英伟达）

骨架：业务分拆 → 上下游全景（瓶颈即投资地图）→ **产品线出货时间表与销量（心脏）** → 价值量迁移表（纵轴）→ 全链估值切面（横轴）→ 外资观点 → 风险 → 结论+追踪。

要点：
- **出货时间表是总闸门**：代际×量产窗口×当年角色×网络速率×证据等级。下游所有需求测算从这里引出。
- **价值量迁移表**：用 BOM 拆解（如 VR200 vs GB300 整柜 ASP $780万 vs $399万，各环节 +X%）把源头升级映射到下游每一篇。
- **横向估值切面**：把全链 PE + 现价/目标价摆一起，找结构性错位（"水源便宜水管贵"）。
- **源头篇要回填下游**：定下"2026=800G大年/2027=1.6T大年"后，回到下游专栏修正其测算。

## 二、关键问题的"标准答法"句式库

- **订单分级**："有真实合作，但不是独家——X 被官方命名为生态供应商之一，同名单还有 N 家；它更贴近【间接受益】而非【直供核心】。"
- **行业地位分品类**："极高但要分品类看：T-glass 厚型 95%（垄断），NER 二代 60-70%，NE 一代仅 20-30%（竞争激烈）。笼统说'垄断'会误导。"
- **毛利率全链定位**："46% 在模块厂里顶尖（一般 20-30%），但放全链只是中游——最肥的是 DSP（60%+）和光器件（天孚 57%）。它赚'规模化集成'的钱。"
- **两种涨价模式**："注意：光模块没有'涨价垄断'逻辑（价格年降惯例），靠的是产品升级+硅光降本+规模——和 MLCC/T-glass 的供需紧张提价是完全不同的商业模式。"
- **是否某链主核心的辨析**（链主按所属链选：英伟达/谷歌TPU/苹果…）："是核心受益、但非直供独家。更微妙的是它【既受益又被威胁】——英伟达 GPU 放量利好它，但英伟达主推 CPO 又要砍它配比（1:4→1:1）。"（同理可套谷歌 TPU 链、苹果链）
- **替代难度二分**："A股替代逻辑不是'抢龙头高端份额'（材料壁垒短期啃不动），而是'海外满产→订单外溢+涨价受益'——是互补受益方，不是替代关系。"
- **估值结构错位**："水源便宜水管贵：源头英伟达 15x CY28、低于目标价三成；下游 A股 70-500x、现价超目标价 50-80%。这种倒挂只会以两种方式收敛。"
- **传言数量级证伪**："'明年3000亿'是数量级错误：全球该市场 2026 总盘子才 X 亿，一家做 3000 亿=吃下全球 1.8 倍，产业上不可能。第一反应该问：营收/净利/市值？哪一年？"

## 五、沟通风格偏好（写作时遵守，可按自己习惯调整）

- 结论先行，再给理由，不铺垫背景。
- 不谄媚：不说"很好的问题"、不开头"当然可以"。方案有问题直接指出，发现更好做法直接说。
- 遇到口径模糊/传言，主动证伪并教方法（"以后听到 X 先问 Y"）。
- 给真实判断和风险，不只罗列数据。现价 vs 目标价、估值透支这类话直说。
- 中文为主，代码/变量/英文术语用英文。
