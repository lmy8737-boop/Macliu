# 来源质量评分

来源评分用于排序和审计证据，不用于把观点自动变成事实。证据等级始终沿用知识库的 `P0-P3`，评分不能提升等级。

## 证据等级

| 等级 | 典型来源 | 使用边界 |
|---|---|---|
| P0 | 监管/交易所文件、公司正式披露、官方数据、论文原文 | 可作为事实底座，仍需核对日期和口径 |
| P1 | 可信媒体、行业协会、独立研究 | 用于补足P0，重要结论尽量交叉验证 |
| P2 | 卖方报告、专家访谈、会议纪要 | 作为观点、假设和线索，不直接写成事实 |
| P3 | 社交媒体、自媒体、聚合页、匿名截图 | 只作为待验证线索 |

## 评分维度

满分10分：来源属性4分、直接性2分、时效2分、独立交叉验证2分。

- 来源属性：由来源类型映射到0-4分，同时固定其P0-P3等级。
- 直接性：原始页面/完整文件2分，可靠摘录1分，二手转述0分。
- 时效：30天内2分，一年内1分，更旧或日期未知0分；慢变量可显式标记 `evergreen`。
- 独立来源：至少2个相互独立来源1分，至少3个2分。同一稿件转载不算独立来源。

分数只决定处理优先级：

- 8-10：强证据候选，按证据等级使用。
- 5-7：支持性证据，需要补原始来源或交叉验证。
- 0-4：线索，不应承载关键结论。

`P2/P3` 即使获得较高分，也仍然只能作为观点或线索。来源之间互相矛盾时标记 `disputed`，不得取平均后宣称已核实。

## 命令

```bash
python3 scripts/source_quality.py \
  --claim "公司上调资本开支" \
  --url "https://www.sec.gov/example" \
  --directness direct \
  --published-at 2026-07-05 \
  --independent-sources 2 \
  --corroboration confirmed

python3 scripts/source_quality.py --input claims.jsonl --jsonl
```

批量输入每行一个JSON对象，字段名与命令参数一致。未知域名不会被自动包装成可靠来源；需要显式提供 `source_type`。
