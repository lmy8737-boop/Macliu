# 团队架构与协作 SOP

> **v6.7.5 适用边界**：本文件只供用户明确要求旧式日常交易自动化时参考，不用于普通公司/行业研究、正式报告或知识库 `PATCH_NOTE`。下方六角色图和时间表是交易场景示例，不是全员要求；实际角色按主 `SKILL.md` 的关键变量选择，4 号仅由明确交易意图触发。所有角色共用 3 号按变量维护的证据表并只给职责增量；需要独立第二意见时另走独立取证。若与主 `SKILL.md` 或 `orchestrator.md` 冲突，以后二者为准，风险阈值仍按现行红线执行。

## 每日工作流（标准时间表）

| 时间 | 角色 | 输入 | 输出 |
|------|------|------|------|
| 07:00 | 3号 | 隔夜数据 | 数据仓库更新 |
| 09:00 | 1号 | 3号宏观数据 | 宏观研判+配置权重表 |
| 09:30 | 2号 | 3号扫描+1号宏观+holdings | A+B双池Watchlist |
| 10:00 | 4号 | structures.json+holdings | 信号入库+Markdown摘要 |
| 10:15 | 5号 | 1234全部产出+holdings | 打分+幻觉审计+STATUS码 |
| 10:30 | router | 5号输出 | PASS→6号 / REJECT→回炉 / FORCED_PASS→警告 |
| 11:00 | 6号 | 全员产出+SQLite信号 | 一页纸内参 |
| 11:15 | 你 | 内参 | 批示 A/B/C |
| 15:30 | 3号 | T+N到期信号 | 自动结算盈亏 |

## 状态机路由协议

```
5号产出
   ↓ 解析 STATUS: PASS|REJECT
PASS → 进入 6号秘书
REJECT (retry<2) → 自动回炉 1234号 + 5号意见 + 重试次数
REJECT (retry≥2) → FORCED_PASS + [高风险未决] 标签 → 6号
```

## 风控红线（7 条不可逾越）

| # | 规则 | 处罚 |
|---|------|------|
| 1 | 单只标的 ≤ 7% | 立即否决 |
| 2 | 单行业 ≤ 25% | 48h 内调整 |
| 3 | 总仓位 ≤ 80% | 触发警告 |
| 4 | 必须设止损 | 信号无效 |
| 5 | 止损必须执行 | 严重纪律 |
| 6 | 单日亏损 ≤ 3% | 当日熔断 |
| 7 | 月度回撤 ≤ 8% | 全面复盘 |

## 信号分级

| 级别 | 胜率 | 盈亏比 | 处理 |
|------|------|--------|------|
| S | ≥70% | ≥2.0 | 重仓信号（5-7%）|
| A | ≥60% | ≥1.5 | 标准信号（3-5%）|
| B | ≥55% | ≥1.2 | 轻仓信号（1-3%）|
| C | 不达标 | - | 丢弃，不输出 |
